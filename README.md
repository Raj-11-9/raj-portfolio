# Cloud Engineer Hub

Build a modern, professional, responsive personal portfolio website by extracting all relevant information directly from my uploaded resume.

1. Resume Data Extraction

First, analyze my uploaded resume carefully and extract:

Full name

Professional title / role

Career objective or professional summary

Education

Technical skills

Networking skills

Cloud/AWS skills

Linux skills

DevOps/tools

Programming/scripting skills

Certifications

Internship/training

Work experience

Projects

Achievements

Soft skills

Interests

Contact information

GitHub

LinkedIn

Any other professional links

Do not invent information.
Use the resume as the primary source of truth.

If information is missing from the resume, do not create fake experience, certifications, companies, achievements, or statistics.

2. Overall Portfolio Theme

Create the website around my actual professional role mentioned in the resume.

If my resume identifies me as an IT Infrastructure / Cloud / Network professional, use a visual theme inspired by:

Cloud Infrastructure + Computer Networks + Linux + DevOps

The website should feel like a professional engineer's portfolio, NOT a generic software developer portfolio.

Use visual concepts such as:

Cloud infrastructure

Network topology

Servers

Containers

Linux terminal

AWS/cloud architecture

Data flow

Infrastructure monitoring

Keep the design elegant and professional. Do not overload the page with excessive animations.

22. Important Accuracy Rules

These rules are critical:

Extract information from my resume instead of asking me to manually enter everything.

Never invent companies, certifications, degrees, projects, job titles, achievements, or technologies.

Do not exaggerate my experience.

If a technology is not present in the resume, don't claim that I know it.

Preserve accurate dates and company names from the resume.

Make the professional title match the strongest role represented in my resume.

Prioritize Networking, Cloud, Linux, AWS, Infrastructure, Docker, and Automation if those are actually present.

Make the portfolio suitable for recruiters and technical hiring managers.

The website should communicate that I am an IT Infrastructure / Cloud-oriented professional with networking fundamentals, rather than simply a generic fresher/developer.

Make the final result look like a portfolio that could realistically be used when applying for jobs.

Create a portfolio that looks modern, technically credible, recruiter-friendly, and professional enough to use as my primary personal website.
